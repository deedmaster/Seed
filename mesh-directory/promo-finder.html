🧮 Cheapest route — how to stack it

The cheapest order is almost always a stack, not one code:

  1. Start with a brand-new account on the app you haven't used yet — that's where the biggest codes live (40% off DoorDash, $25 off Grubhub, up to $30 off Uber Eats).
  2. Hit the minimum, not the menu. A $15 order for a $5-off code beats a $14 order with no code. Add a drink or a side to cross the line.
  3. Kill the delivery fee with a membership (DashPass / Uber One, $4.99 student) if you order more than twice a month — the fee is usually $2–$6 an order, so two orders pays for it.
  4. Compare the same meal on two apps before you buy — one app's 40% off can still lose to another app's $25 off once fees are added.

⚠️ The new-user trap: new-user codes only work on accounts with zero order history. If you've ever ordered — even once, even years ago — the code will fail at checkout. That's the most common reason a "working" code doesn't work. Making a second account to dodge this can get the account banned; the safe move is to rotate to an app you genuinely haven't used yet.
